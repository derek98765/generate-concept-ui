# Web mode

Rules for website and landing page images. Read with the main SKILL.md.

## Image count and format

- One **horizontal** image per section (16:9, 16:10 or 21:9). Never one tall image
  of the whole page.
- No count given: hero only = 1, landing page / product page / portfolio = 6, full
  site / marketing site = 8.
- Mix section sizes: some big and rich, some small and mostly empty space, some
  medium. Keep the gap between sections even.

Default section lists:

- **4:** hero, features, testimonial, CTA
- **6:** hero, trust bar, features, product showcase, testimonials, CTA
- **8:** hero, trust bar, features, product showcase, use cases, testimonials,
  pricing, CTA
- **12:** add problem/solution, workflow, metrics or integrations, FAQ, footer

## Style choices

Pick one of each and write it in `style.md`.

- **Theme:** clean light (cream, paper, sharp dark text) · deep dark (charcoal,
  graphite) · bold solid color (oxblood, royal blue, forest, vermilion) · quiet
  neutral (bone, sand, stone).
- **Type:** clean grotesk · refined grotesk · expressive display · compressed
  statement · serif + sans editorial · Swiss sans with strong hierarchy.
- **Layout system:** bento grid · alternating editorial blocks · poster-like
  stacked story · gallery-led · Swiss grid · asymmetric marketing flow.
- **Hero size:** giant statement (huge type, large image) · mid editorial (balanced)
  · mini minimal (small logo, short line, thin CTA, mostly empty space — calm, not
  weak). Pick one firmly.
- **Theme thread (optional):** artifact, journey, precision tool, living system,
  stage, archive. Let it shape images and short copy across the page.
- **One surprise:** exactly one unexpected but readable touch on the page, e.g. one
  oversized numeral, one material switch, a side-rail note, a macro crop. It must
  help scanning or brand recall, not be a gimmick.

## Per-section choices

Each section picks a layout anchor, a background and a CTA style.

**Layout anchors:** centered statement · top-left lead · bottom-left text over
image · bottom-right CTA cluster · left-third text + image (use sparingly, never
twice in a row) · right-third text + image · centered low over image · off-grid
offset · stacked center · image as canvas with text in a clean area.

**Backgrounds:** solid + inline image · subtle texture, paper or grid · full-bleed
image with tonal overlay · side image (50/50, 60/40) · flat color block + small
detail crop · soft palette-matched gradient · graded atmospheric photo · duotone
photo · soft vignette + product · fine noise over solid · two color fields meeting.

**CTA styles:** solid pill · outline · underlined link with arrow · full-width
banner · huge headline with a small CTA · CTA as a caption under a visual. Use more
than one style across the page. The main action must stay obvious; secondary
actions must look secondary.

**Variety check** across the set:
- The same layout anchor never runs more than 2 sections in a row.
- The same background never runs more than 3 sections in a row.
- Unless the brief is minimal, include at least one full-bleed or photo background
  and at least one mini, mostly-empty section.
- For minimal briefs (clean, typography-only, Swiss) skip these; restraint is the
  design.

## Brief to direction

- **Minimal / clean / Swiss:** mini hero, solid surfaces, stacked center, lots of
  empty space, no forced full-bleed images.
- **Editorial / magazine / fashion:** mid or giant hero, side images or duotone,
  off-grid layouts, strong type contrast.
- **Cinematic / luxury / bold:** giant hero, full-bleed graded images, text low or
  bottom-left over the image.
- **SaaS / fintech / infra:** mid hero, solid + product shots, very soft gradients,
  clear product framing, trust first.
- **Agency / studio / portfolio:** giant or mini hero (pick one), bold background
  changes, poster-like off-grid layout.
- **Shop / product page:** product-led mid hero, big product photos, CTAs
  unmistakable.

## Every page must sell

Each section has a job: hook, proof, explain or convert. Even an artistic page
reads as a real site:
- The hero says the value in seconds and offers one clear next step.
- Proof (logos, quotes, numbers) feels earned, not stuffed.
- The last section closes with one strong CTA and a trust cue.
- Charts only when the product needs them (analytics, pricing, infra). Otherwise
  use quotes, timelines and real screenshots as proof.
- No unreadable "trusted by" logo strips or meaningless carousel dots.

## Signature components

Pick up to 4 and reuse them across the page: staggered square masonry · stacked
3D card deck · expandable slice row · gapless bento grid · brand marquee · rotated
photo arc · thin rhythm lines · off-grid editorial block · product UI panel stack ·
quote wall · oversized metrics strip · layered image crops. Each must look
deliberate and tidy, never scrapbook-random.
